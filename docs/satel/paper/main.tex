\begin{abstract}
SATEL describes test intentions over algebraic, state-based specifications.
This working paper studies a restricted synchronous implementation in which
symbolic selection produces ground tests, concrete reference execution admits
those tests, and software implementations are exercised through public calls.
We distinguish compatibility of an observed response history from evidence about
a branching requirement. A set-valued reference oracle retains nondeterministic
alternatives, while a conservative per-run evaluator supplies witnesses,
counterexamples or inconclusive HML evidence. Existing reproducible campaigns
cover three procedural service families and five deliberately faulty variants;
their results demonstrate observable mismatches without establishing general
conformance. This draft fixes a proposed implementation baseline and semantic
contract, identifies precise thesis anchors, and separates measured evidence from
pending correspondence and soundness obligations.
\end{abstract}
